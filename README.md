# Guardian Desk Website

Bold, vibrant, maximalist landing page for Guardian Desk built with React + Vite and tuned for scroll-to-reveal animations.

## Run In GitHub Codespaces

1. Open this repository in GitHub Codespaces.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev -- --host 0.0.0.0 --port 5173
```

4. Open the forwarded port preview in Codespaces.

## Build For Production

```bash
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```
